<details open>

<br>

> Welcome to the official repository for **CPE 010: Data Structures and Algorithms**. This interactive archive contains laboratory implementations, custom algorithm headers, performance benchmarks, and theoretical time complexity analyses written in standard **C++**. Files are organized by term: **Prelim**, **Midterm**, and **Finals**.

### 🎯 Key Learning Outcomes
* 🧱 **Fundamental Data Structures:** Linked Lists (Singly & Doubly), Stacks, Queues, and dynamic node structures.
* 🌳 **Trees & Graphs:** Binary Search Trees, general trees (pre-order, in-order, post-order traversals), and graph representations (adjacency list & adjacency matrix).
* ⚡ **Sorting Algorithms:** Bubble, Selection, Insertion, Shell, Merge, and Quick Sort implementations with timed benchmarks.
* 🔍 **Searching Techniques:** Linear Search and Binary Search algorithms across arrays and linked node topologies.
* 🧠 **Algorithm Design:** Dynamic programming with memoization and multithreading with `std::thread`.
* ⏱️ **Complexity Analysis:** Asymptotic Analysis ($\mathcal{O}(n)$, $\mathcal{O}(n^2)$, $\mathcal{O}(n \log n)$, $\mathcal{O}(\log n)$) and experimental timing with `std::chrono`.

</details>

<details>
<summary><b>⚙️ Compilation & Execution Instructions</b></summary>
<br>

To compile and run any algorithm module locally using Standard GCC/G++:

```bash
# 1. Clone the repository
git clone https://github.com/MendozaRoycpe/CPE010-Data-Structures-and-Algorithms.git

# 2. Navigate into project folder
cd CPE010-Data-Structures-and-Algorithms

# 3. Navigate into a specific term and activity folder (e.g., MIDTERM/HOA 7p1)
cd "MIDTERM/HOA 7p1"

# 4. Compile C++ source files
g++ -O2 -std=c++17 MAIN.cpp -o app

# 5. Execute binary
./app
```

> **Notes:**
> * Each activity folder is self-contained. Compile the `.cpp` file that contains `main()`; the headers in the same folder are included automatically.
> * On Windows, the executable is `app.exe`; run it with `.\app.exe`.
> * `FINALS TERM/HOA 13p1` uses `std::thread`. On Linux/macOS, add the `-pthread` flag when compiling.

</details>
